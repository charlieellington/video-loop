# Configuration (`project.toml`, schema 1)

Plain English: every setting, what it does and its default. Settings are layered — built-in
defaults → the profile you name → your `project.toml` → one-off `--set section.key=value` on the
command line. Unknown or misspelt settings are an error. Relative paths are relative to the
project folder. Each revision saves the effective settings in
`.video-loop/revisions/rNNN/effective-config.json`. No secrets in this file — ever.

| Setting | Default | Meaning |
|---|---|---|
| `schema_version` | 1 | required |
| **[project]** `title` | "Untitled video" | shown on the board |
| `profile` | "" | `bene` or `charlie` (files in `profiles/`) |
| `media_dir` / `output_dir` | media / output | your media (read-only) and renders |
| **[canvas]** `width` × `height` | 1080 × 1920 | output size (even numbers) |
| `fps` | 30 | output frame rate; every cut is snapped to this frame grid |
| `fit` | blur | off-shape pictures: `blur` (blurred copy behind), `crop` (fill), `contain` (bars) |
| **[narration]** `kind` | recorded-audio | `recorded-audio` (voice recording) or `recorded-video` (talking head) |
| `source` | — | the narration file |
| `takes` | [] | instead of `source`: several talking-head takes joined into one reel |
| `take_gap_s` | 0.3 | black gap between takes (a take boundary is always a cut) |
| **[voice_cleanup]** `source` | none | `elevenlabs` = offer Audio Isolation before transcription |
| `max_offset_ms`, `max_drift_ms`, `max_duration_delta_ms`, `min_speech_retained` | 250, 30, 120, 0.9 | the timing/speech checks a cleaned recording must pass |
| **[transcription]** `source` | elevenlabs | or `import` a word-timed JSON (`transcript`) |
| `model` | scribe_v2 | pinned Scribe model (tested) |
| `language` | auto | or `en`, `nl`, … |

| **[presentation]** `hook` | none | `typed` = typed-text opening (needs a `hook` block in the edit) |
| `interludes` | false | use the edit's `interludes` (b-roll moments with no narration) |
| `grade` | natural | `warm` = the warm grade on talking-head footage |

| **[captions]** `preset` | outline-phrase | `none`, `outline-phrase`, `typewriter-highlight`, `mono-box` |
| `position` | lower | `lower`, `center`, `upper` |

| `max_words`, `max_span_ms` | 5, 1800 | phrase length limits |
| `srt` | true | write the `.srt` sidecar |
| **[music]** `source` | none | `file` (your track) or `elevenlabs` (generated by `music generate`) |

## The edit plan (`.video-loop/revisions/rNNN/edit.json`)
See `prompts/editorial-plan.md` for the full example. Fields: `transcript_sha256` (required,
binds the plan to the transcript), `segments[]` (word ranges kept), `covers[]` (`over_words`,
`media`, `start_s`, `fit`, `hold_until_next`, `sound`, `sound_gain_db`, `why`), `caption_fixes`
(word number → displayed text), `interludes[]`, `hook`, `notes`.

## Imported transcripts
`{"contract":"video-loop/words@1","audio_sha256":"<sha256 of the narration file>","language":"en",
"words":[{"i":0,"text":"Hello","start_ms":120,"end_ms":480}, …]}` — ElevenLabs Scribe JSON
(`words[].start/end` in seconds) is accepted too. If the `audio_sha256` does not match, `ingest
--bind-import` checks that the word times land on speech in this recording before accepting it.
